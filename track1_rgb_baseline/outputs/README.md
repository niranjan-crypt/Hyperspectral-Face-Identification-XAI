# Track 1: RGB Baseline & Explainable AI - Outputs Directory

This directory stores evaluation artifacts, diagnostic plots, trained model checkpoints, and edge deployment benchmarks generated by the Track 1 RGB baseline pipeline.

---

## Output Structure

When running `train_rgb_baseline.py` or the Jupyter notebook `notebooks/01_RGB_Baseline_UISM_Net.ipynb`, results will be populated into the following structure:

```
track1_rgb_baseline/
├── outputs/
│   ├── figures/
│   │   ├── confusion_matrix.png          # Normalized multi-class confusion matrix on test split
│   │   ├── training_curves.png           # Epoch vs loss/accuracy curves (with early stopping checkpoints)
│   │   ├── model_comparison_bar.png      # Comparative bar chart: UISM-Net vs LBP-SVM vs HOG-SVM
│   │   └── xai_saliency_maps/            # Explainable AI diagnostic maps
│   │       ├── gradcam_plus_plus.png     # Grad-CAM++ facial landmark activations
│   │       ├── lime_superpixels.png      # LIME superpixel segment contributions
│   │       └── shap_feature_attributions.png # SHAP Kernel attribution values
│   ├── models/
│   │   ├── rgb_face_cnn_model.keras      # Keras checkpoint for full-precision UISM-Net
│   │   ├── uism_net_fp16.tflite          # FP16 half-precision quantized model for RPi4
│   │   └── uism_net_int8.tflite          # INT8 full integer quantized edge deployment model
│   └── tables/
│       ├── test_classification_report.csv# Precision, Recall, Macro F1, and Overall Accuracy
│       └── edge_latency_benchmarks.csv   # Raspberry Pi 4 inference latency (ms), RAM usage (MB)
```

---

## Output Metric Definitions

- **Overall Accuracy (OA)**: Percentage of correctly classified face instances across test identity splits.
- **Macro F1-Score**: Unweighted mean of class-wise F1 scores, accounting for identity class imbalance.
- **Inference Latency**: Single-frame inference execution time on edge hardware (target: < 50 ms on Raspberry Pi 4 Model B).
- **Quantization Compression Ratio**: File size reduction from full FP32 Keras weights (~14 MB) to INT8 TFLite (~3.5 MB).
